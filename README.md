# Williams Battle Simulator

A simple Java Swing battle simulator for our group project. Two teams face
off across a battlefield with gold, troops, and a castle on each side.

## What's done so far

- Added a `.gitignore` for a Java project.
- Added the basic Swing window scaffold (`App.java` + `BattlefieldPanel.java`)
  — just the game window for now, no simulation logic yet.

This work is on the `add-gitignore` branch, pending merge into `main`.
